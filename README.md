# heidiSQL-Ejercicios-Integridad
Ejercicios SQL - Integridad de la materia Base de Datos - Instituto Tecnologico Beltran 2026
Ejercicios hechos en heidi SQL utilizando el tema Integridad.

Contenido del script:

- Creación de la base de datos y tablas.
- Inserción de datos válidos en Oficinas y Empleados.
- Intentos de inserción incorrectos para probar cada restricción:
    - Código de empleado fuera de rango (menor a 100 y mayor a 1000)
    - Duplicado de documento (tipo_doc + num_doc)
    - Categoría inválida
    - Oficina inexistente (violación de clave foránea)
